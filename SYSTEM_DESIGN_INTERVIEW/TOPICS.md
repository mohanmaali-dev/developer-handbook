How we will study these topics
For each topic, we'll cover only these things:
1. What is it? – Simple explanation.
2. Why do we need it? – What problem does it solve?
3. How does it work? – Internal working and architecture.
4. Real-world example – Where companies use it.
5. Advantages and disadvantages.
6. When should we use it? – And when should we avoid it?
7. Interview questions – Basic to advanced.
